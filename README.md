# little-web-pet

一个纯静态网页桌宠。当前版本的小狗是原创 inline SVG 绘制，不使用图片作为主体，也没有外部资源依赖。

## 运行

直接双击 `index.html` 即可运行，也可以把整个仓库部署到 GitHub Pages。

## 文件

- `index.html`：页面结构和 inline SVG 小狗
- `style.css`：布局、响应式、线条小狗部件动画
- `script.js`：文案、状态管理、按钮交互和 DOM 粒子
- `assets/dog.png`：旧图片文件，当前页面不引用

项目没有框架、没有 npm、没有后端、没有外部依赖。
