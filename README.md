# little-web-pet

一个很小的静态网页桌宠。它只使用 `assets/dog.png` 这一张图片，通过 CSS transform、filter、shadow、伪元素和少量 DOM 粒子做出待机、注意、点击、摸摸、打工和换一句动画。

## 运行

直接双击 `index.html` 即可运行，也可以把整个仓库部署到 GitHub Pages。

## 文件

- `index.html`：页面结构
- `style.css`：布局、响应式和动画
- `script.js`：文案、状态管理、按钮交互和粒子
- `assets/dog.png`：桌宠图片

项目没有框架、没有 npm、没有后端、没有外部资源依赖。
